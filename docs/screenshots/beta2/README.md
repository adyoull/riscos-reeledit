# ReelEdit 0.3 Beta 2 screenshots

Taken on RISC OS 5 in the RISC OS for Linux testbed, with the project files
made from ReelEdit's own editing code.

The video in them is from **Big Buck Bunny**, (c) copyright 2008, Blender
Foundation, [www.bigbuckbunny.org](https://peach.blender.org), licensed
under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
The screenshots show frames of it as edited in ReelEdit (cut, coloured,
zoomed, wiped, frozen, with titles and overlays).
